# Checklist de cumplimiento de la Guia para Participantes

## Modulo 1 - Beneficiarios y familias
- [x] Registrar beneficiario.
- [x] Buscar beneficiario antes de crearlo.
- [x] Consultar beneficiario.
- [x] Actualizar beneficiario.
- [x] Datos sociodemograficos y de contacto.
- [x] Codigo interno generado por el sistema.
- [x] Documento opcional cuando no aplica.
- [x] Prevencion de duplicados por tipo + numero de documento.
- [x] Revision de posibles coincidencias sin documento.
- [x] Registro y relacion con familia.
- [x] Consentimiento para tratamiento de datos.

## Modulo 2 - Programas y participacion
- [x] Crear y consultar programas.
- [x] Linea de intervencion.
- [x] Vincular beneficiario a uno o varios programas.
- [x] Fecha de vinculacion.
- [x] Estado de participacion: INSCRITO, EN_PROCESO, FINALIZADO, RETIRADO.

## Modulo 3 - Atencion y seguimiento
- [x] Atencion/ayuda con fecha y tipo.
- [x] Descripcion.
- [x] Responsable.
- [x] Resultado.
- [x] Remision cuando corresponda.
- [x] Seguimiento con fecha.
- [x] Avance/cambio/novedad.
- [x] Observacion.
- [x] Accion pendiente.
- [x] Proximo contacto mediante fechaProximoSeguimiento.

## Modulo 4 - Consultas y reportes
- [x] Ficha consolidada del beneficiario.
- [x] Familia incluida en la ficha consolidada.
- [x] Participaciones con programa, linea y estado.
- [x] Atenciones y seguimientos incluidos.
- [x] Beneficiarios unicos.
- [x] Participaciones por programa.
- [x] Atenciones registradas.
- [x] Seguimientos pendientes.
- [x] Reportes agregados sin datos personales.

## Proteccion de datos y enfoque de acceso
- [x] Estado de consentimiento.
- [x] RBAC existente se conserva.
- [x] Restriccion de informacion por rol/municipio existente se conserva.
- [x] IA conserva filtros y limites ya implementados.

- [x] Deteccion y resolucion de duplicados.
- [x] Unificacion de fichas.
